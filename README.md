# PhotoSwipe

  <img src="PhotoSwipe/Assets.xcassets/AppIcon.appiconset/AppIcon-1024.png" width="160" alt="PhotoSwipe App Icon">
</p>

一个本地优先的 iOS 相册整理 App：

- App 图标：海边日出与瑜伽人物，由用户提供的屏幕照片轻度润色制作
- 左滑：加入待删除队列
- 右滑：保留
- 上滑：加入系统收藏
- 下滑：加入已有相册，或新建相册后加入
- 左上角：选择“全部照片”或指定相册作为整理来源
- 左上角日历：按今天、最近 7 天、最近 30 天、今年或自定义日期范围整理
- 日期范围内可选择最新优先或最早优先
- 支持 iPhone 镜像与外接键盘：← 删除、→ 保留、↑ 收藏、↓ 加入相册
- Live Photo 出现时自动完整播放，点击“实况”标记可再次播放
- 右上角相似照片按钮：在当前相册和日期范围内检查相似照片
- 相似照片会分组并排对比，可一次选择多张加入待删除队列；每组至少保留一张
- 对比卡片显示拍摄日期、文件大小、占当前相似组空间比例和照片分辨率
- 右上角盾牌：查看本地隐私说明、管理照片权限和安全联系方式
- 可清除全部整理记录与当前待删除队列，不会删除任何照片
- 撤销上一步
- 已整理照片会在下次启动时自动过滤
- 整理结束后统一确认删除

照片只通过 Apple PhotoKit 在设备本地处理。App 不上传照片，也不包含广告或追踪 SDK。

## 运行

1. 如果这台 Mac 是首次使用 Xcode，请先在终端运行
   `sudo xcodebuild -license`，阅读后输入 `agree`。
2. 使用 Xcode 26 或更新版本打开 `PhotoSwipe.xcodeproj`。
3. 在 Signing & Capabilities 中选择自己的 Team。
4. 连接 iPhone，并选择真机作为运行目标。
5. 首次启动时授权照片访问。

模拟器也能运行，但需要先向模拟器照片图库添加测试图片。

## 当前版本

V0.1 MVP：相册权限、照片读取、按相册与日期整理、相似照片分组对比、四向滑动、相册归类、整理记录、撤销、批量删除确认和整理统计。

相似照片检查仅处理当前范围中最多 500 张可在本机读取的照片，分析结果不会上传。

源码已使用 iOS 17 Simulator SDK 通过 Swift 类型检查，并已在 iPhone 真机运行。
正式提交 App Store 前仍需补充公开隐私政策 URL、商店截图和审核材料。

## 隐私与安全

- 照片、缩略图与相似度分析结果不会上传。
- App 仅在设备本地保存已整理照片的 PhotoKit 标识。
- 删除操作始终经过待删除队列和 Apple 系统确认。
- 安全问题请参阅 [SECURITY.md](SECURITY.md)。
